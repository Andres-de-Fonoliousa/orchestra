# Orchestra Distribution Strategy

This document outlines our strategy to gain traction and community engagement for Orchestra.

## Goal
Establish Orchestra as the *de-facto* persistent memory and orchestration tool for the `opencode` ecosystem.

## Target Audience
- `opencode` users who suffer from "chat amnesia."
- AI developers looking for persistent, Git-backed memory.
- Automation-focused engineers building agent swarms.

## Phase 1: Launch Prep (Internal)
- [x] Stripe-grade `README.md`.
- [x] Roadmap documentation.
- [x] Clear `CONTRIBUTING.md` for onboarding.

## Phase 2: Community Outreach
- **Hacker News (Show HN):** Emphasize the "No more chat amnesia" value proposition.
- **Reddit (r/LocalLLaMA, r/OpenSource, r/AI_agents):** Engage in discussions, highlight the autonomy and persistence features.
- **GitHub Trending:** Ensure the repository has high-quality keywords, badges, and a clear "Try it" path.

## Phase 3: Growth Loops
- **Plugin Marketplace:** Encourage community-built plugins for journaling/automation.
- **Tutorials:** Create "Orchestra in 5 minutes" blog post or short video showing the `/handoff` flow.
